# ADT Stock V52 — Windows

## الإصلاحات
- قائمة اقتراحات العملاء لا تظهر حتى يبدأ المستخدم البحث.
- تثبيت ألوان خانة العميل والنتائج لتظل الأسماء واضحة بعد التركيز والاختيار.
- الحفاظ على مسار الطباعة الصامتة في تطبيق Electron.

## البناء عبر GitHub
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. افتح Actions وشغّل **Build ADT Stock for Windows** عبر **Run workflow**.
3. بعد نجاح البناء، نزّل Artifact باسم **ADT-Stock-Windows-Installer** وفيه ملف EXE.

لم يتم تشغيل GitHub Actions أو اختبار الطباعة على طابعة فعلية من هذه البيئة.
